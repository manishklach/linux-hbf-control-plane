# Maintainers

## Project Status

This repository is an experimental RFC artifact, not an upstream Linux subsystem.

It exists to support architecture discussion around a possible HBF control plane for AI inference memory hierarchies. Review, critique, and design discussion are more valuable than assumptions of feature completeness.

## Scope

Maintainers are responsible for:

- repository documentation
- RFC patch framing
- userspace mock examples
- issue triage related to control-plane design

Maintainers are not claiming:

- upstream Linux ownership
- support for shipping HBF hardware
- stable ABI commitments

## Preferred Contributions

- design review

- API-shape critique

## Contribution Expectations

- keep claims precise and non-speculative
- avoid vendor-specific hardware assumptions unless clearly labeled
- preserve separation between RFC scaffolding and upstream kernel claims
- include rationale for any proposed UAPI changes
